## 초록 / Abstract

생성형 AI가 지식 생산의 주요 도구로 부상한 현재, 인간 고유의 인지 능력—특히 구조를 인식하고 연구 질문을 생성하는 능력—은 재조명을 요구받고 있다. 본 논문은 두 가지 이론적 프레임워크를 통합한다.

첫째, **구조 인식 이론(SRT, Structure Recognition Theory)**은 인간이 패턴에서 "설명적 유의성"을 탐지하고 연구 질문을 생성하는 인지적 메커니즘을 기술한다. 본 논문은 SRT의 핵심 가설 H1–H10을 카르노맵 사례 연구로 구체화한다.

둘째, **인간-AI 연구 연속성 이론(HARCT, Human-AI Research Continuity Theory)**은 장기간 인간-AI 협력 연구가 단순한 지능의 문제가 아니라 "연구 연속성"의 문제임을 논증한다. 목표 보존, 인지 노동 분담, 외부화 기억이 핵심 개념이다.

카르노맵 XOR 체커보드 패턴 발견 과정을 사례로, SRT와 HARCT가 어떻게 상호보완적으로 인간-AI 연구 생태계를 설명하는지를 보인다. 아울러 생성형 AI 시대 공학교육의 방향으로 "결과 중심"에서 "사고 과정 중심"으로의 전환을 제안한다.

**핵심어:** 구조 인식 이론, SRT, 인간-AI 연구 연속성, HARCT, 생성형 AI, 공학교육, 설명적 유의성, 목표 보존

## 1. 서론

### 1.1 문제 제기

생성형 AI는 복잡한 논리 연산, 코드 작성, 문서 생성에서 인간을 능가하거나 대등한 성능을 보인다. 그러나 AI가 "구조를 보는가?"라는 질문에는 아직 명확한 답이 없다.

본 연구는 이 질문을 카르노맵이라는 구체적 맥락에서 탐구한다. 카르노맵의 XOR 체커보드 패턴은 교과서에 명시되어 있지 않음에도 불구하고, 일부 인간 연구자는 이 패턴에서 "설명적으로 유의미한 구조"를 인식하고 연구 프로그램을 시작하였다. 동일한 패턴이 생성형 AI에 제시되었을 때, AI는 패턴을 "재현"하지만 그 유의성을 "발견"하지는 못하는 경향이 있다.

### 1.2 연구 질문

1. 인간은 어떤 메커니즘으로 구조적 패턴에서 연구 가치를 탐지하는가? (SRT)
2. 장기간 인간-AI 협력 연구는 어떻게 지속될 수 있는가? (HARCT)
3. 생성형 AI 시대 공학교육은 어떤 방향을 가져야 하는가?

## 2. 구조 인식 이론 (SRT)

### 2.1 핵심 정의

**정의 2.1 (구조, Structure):** 다수의 개별 사례에서 귀납적으로 추출된, 명시적으로 표현 가능하고 설명력을 갖는 규칙성.

**정의 2.2 (설명적 유의성, Explanatory Significance):** 관찰된 패턴이 더 깊은 이론적 탐구를 정당화할 만큼 비자명하고 체계적임을 직관적으로 판단하는 인지적 평가.

**정의 2.3 (주의 게이팅, Attention Gating):** 무수히 많은 패턴 중 유의미한 것을 선별하는 인지적 필터링 메커니즘.

### 2.2 SRT 핵심 가설 (H1–H10)

| 가설 | 내용 | 카르노맵 사례 |
|------|------|-------------|
| H1 | 구조 인식은 패턴 매칭이 아닌 의미 생성 과정이다 | XOR 체커보드는 "예외"가 아닌 "규칙"으로 인식됨 |
| H2 | 설명적 유의성은 비자명성(non-triviality)에서 발생한다 | 24→3 동치류는 직관에 반하는 결과 |
| H3 | 인간은 대칭성을 우선적으로 주목한다 | XOR/XNOR 체커보드의 완전 대칭성 |
| H4 | 구조 발견은 반례가 아닌 사례 확인으로도 시작된다 | 여러 변수 배치에서 동일 패턴 반복 관찰 |
| H5 | 개념은 발견 이후 렌즈(lens)로 작동한다 | "동치류" 개념 형성 후 모든 배치를 이 관점으로 재검토 |
| H6 | 설명 욕구는 확인 욕구보다 강하다 | "왜 3개인가?"가 "몇 개인가?"보다 강력한 동기 |
| H7 | 협력 환경은 구조 발견을 가속한다 | AI와의 대화에서 가설이 명시화됨 |
| H8 | 수학적 형식화는 구조 인식을 안정화한다 | D₄ 군론 증명 후 동치류가 "확실해짐" |
| H9 | 구조 공간의 크기는 탐구 지속성에 영향을 준다 | F₄의 65,536개 함수 → 연구 확장 |
| H10 | AI는 구조를 재현하지만 유의성을 판단하지 않는다 | AI는 체커보드를 그리지만 "왜 중요한가"를 묻지 않음 |

### 2.3 SRT의 연구 생성 모델

```
관찰 → 패턴 인식 → 유의성 평가 → 개념화 → 형식화 → 새 연구 질문
              ↑                                          ↓
         주의 게이팅                              개념이 렌즈가 됨
```

## 3. 인간-AI 연구 연속성 이론 (HARCT)

### 3.1 핵심 테제

**HARCT 테제:** 장기간 인간-AI 협력 연구의 지속 가능성은 지능의 크기보다 **연구 연속성(research continuity)**의 설계에 의해 결정된다.

### 3.2 네 가지 이론적 구성 요소

**① 목표 보존 이론 (Goal Preservation Theory)**
- 정보보다 목표의 보존이 더 근본적이다.
- 목표는 재구성을 가능하게 하지만, 방향 없는 정보는 사용 불가능한 아카이브가 된다.

**② 인지 건축 이론 (Cognitive Architecture Theory)**

| 구성 요소 | 역할 | 도구 |
|-----------|------|------|
| 인간 | 목표 보존 + 유의성 판단 | 직관, 장기기억 |
| AI 시스템 | 추론 + 재구성 | LLM, 코드 실행 |
| 아티팩트 | 문맥 보존 | MD 문서, 저장소, TODO |

**③ 재구성 비용 이론 (Reconstruction Cost Theory)**
- 문서화 품질은 협력 효율성을 직접 결정하는 경제적 변수다.
- 재구성 비용 = f(문서 불완전성, 세션 간 간격, 컨텍스트 복잡성)

**④ 외부화 기억 (Externalized Memory)**
- 문맥은 활성 참여자 외부(저장소, 문서)에 저장된다.
- 외부화 기억이 없으면 각 세션은 처음부터 시작이 된다.

### 3.3 HARCT 실증 사례: 본 연구 프로그램

본 연구 프로그램(Papers 1–8)은 HARCT의 살아있는 사례이다:
- **목표 보존**: "카르노맵의 구조적 패턴이 왜 그러한가"라는 핵심 질문이 7개 논문에 걸쳐 유지됨.
- **외부화 기억**: 각 저장소의 README, HANDOVER.md, TODO.md가 문맥을 보존.
- **재구성 비용**: HANDOVER 문서가 없을 경우 AI 세션 재시작 시 큰 비용 발생.

## 4. SRT와 HARCT의 통합: 연구 생태계 모델

### 4.1 통합 모델

SRT는 **연구 질문의 생성**을, HARCT는 **연구 질문의 지속**을 설명한다.

```
[SRT]                    [HARCT]
구조 인식                  연구 연속성
→ 유의성 판단              → 목표 보존
→ 개념화                  → 외부화 기억
→ 연구 질문 생성           → 재구성 효율
         ↕ 상호 피드백
    장기 연구 프로그램
```

### 4.2 생성형 AI와 인간의 역할 분담

| 역할 | 생성형 AI | 인간 |
|------|-----------|------|
| 패턴 재현 | ✅ 우수 | ✅ 가능 |
| 유의성 판단 | ❌ 부재 | ✅ 핵심 |
| 목표 보존 | ❌ 세션 간 망각 | ✅ 장기 유지 |
| 형식화 지원 | ✅ 우수 | ✅ 방향 제시 |
| 새 질문 생성 | ❌ 제한적 | ✅ 핵심 |

## 5. 교육적 함의

### 5.1 "결과 중심"에서 "사고 과정 중심"으로

기존 공학교육: **최소화 절차** → 최소 논리식 도출  
제안하는 방향: **구조 인식 과정** → "왜 이 패턴인가?" 질문

### 5.2 생성형 AI 시대 교육 모델 제안

1. **AI 도구 사용 허용 + 사고 과정 평가**: 결과물이 아닌 과정을 평가한다.
2. **구조 인식 훈련**: 다양한 표현 방식에서 동일한 구조를 찾는 연습.
3. **연구 연속성 교육**: 문서화, 목표 명시화, 인수인계 능력을 정규 커리큘럼에 포함.

## 6. 결론

본 논문은 SRT(구조 인식 이론)와 HARCT(인간-AI 연구 연속성 이론)를 통합하여, 생성형 AI 시대 인간 연구자의 고유한 역할—**유의성 판단과 목표 보존**—을 이론적으로 정립하였다.

생성형 AI가 발전할수록, 인간 고유의 가치는 "더 많이 아는 것"이 아닌 "더 잘 질문하는 것"에 있다.
